A simple flashcard app for learning languages.

## Getting started

Requires Node.js 22.13 or newer.

```sh
npm install
npm start
```

Open http://localhost:3000 and sign up.

All your data is stored in `data/lgdeck.db`.
## Hosting (cPanel)

In "Setup Node.js App", pick Node.js 22.13 or newer, set the startup file to `server.cjs`, then run NPM install and start the app.
